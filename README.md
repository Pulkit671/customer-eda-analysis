# 📊 Customer Data Analysis (EDA Project)

## 📌 Overview

This project focuses on **Exploratory Data Analysis (EDA)** of a cleaned customer dataset to extract meaningful insights about customer behavior, spending patterns, and value segmentation.

The objective is to transform raw data into actionable insights that can help businesses make **data-driven decisions**.

---

## 🎯 Objectives

* Understand customer demographics and behavior
* Analyze relationships between income, spending, and customer value
* Identify high-value customer segments
* Generate insights using visualizations

---

## 📂 Dataset Description

The dataset contains the following features:

| Column Name          | Description                               |
| -------------------- | ----------------------------------------- |
| Age                  | Age of the customer                       |
| Income               | Annual income of the customer             |
| Spending_Score       | Score assigned based on spending behavior |
| Membership_Years     | Number of years as a member               |
| Purchase_Frequency   | Number of purchases made                  |
| Last_Purchase_Amount | Amount spent in last purchase             |
| Customer_Value       | Overall value of the customer             |
| Age_Group            | Categorized age group                     |

## 🔍 Key Insights

* Customers with higher **income tend to have higher customer value**
* Spending behavior varies significantly across **age groups**
* Customers with longer **membership duration show higher engagement**
* Purchase frequency positively impacts **customer value**
* Strong correlation observed between **income and spending patterns**

## 🚀 How to Run the Project

1. Clone the repository:

```
git clone https://github.com/your-username/customer-eda-analysis.git
```

2. Navigate to the project folder:

```
cd customer-eda-analysis
```

3. Install dependencies:

```
pip install -r requirements.txt
```

4. Run the notebook or script:

```
jupyter notebook
```
